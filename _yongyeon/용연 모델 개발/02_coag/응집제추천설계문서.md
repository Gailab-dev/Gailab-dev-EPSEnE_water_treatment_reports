# 용연정수장 응집제 예측모델 성능비교 설계문서

## 1. 목적과 범위

본 문서는 `용연_응집제공정_소독공정_통합.parquet`의 실제 태그를 기준으로, 응집제 관련 설정값을 예측하는 후보 모델풀의 성능을 비교하는 1단계 설계를 정의한다. 비교 대상은 **다변수 회귀, XGBoost, Random Forest, GRU, LSTM**이다.

이번 단계의 산출물은 동일한 데이터·동일한 시간순 검증 조건에서의 모델별 성능 비교표와 구간별 오류 분석이다. 약품 선택, 주입량 추천, 앙상블, 운전자 화면, 자동제어는 범위에서 제외한다.

## 2. 공정 기준과 설계 전제

「제2장 표준처리 공정 진단_용연_최종」의 혼화 공정 진단을 다음과 같이 반영한다.

| 항목 | 용연정수장 확인 조건 | 모델 비교 설계 반영 |
| --- | --- | --- |
| 응집제 | 평상시 PAC, 수질 악화 시 PAHCS | 약품 종류를 구분하는 실제 운전 이력이 확보되기 전까지는 약품 선택 모델을 만들지 않는다. |
| 주입 위치 | 착수정 낙차부 | 원수 수질 시각과 주입 설정 시각을 같은 1분 단위로 정렬한다. |
| 현행 결정 방식 | 조견표·Jar-test 후 유량비례 자동주입 | 현행 설정 태그는 비교용 정답값으로만 사용한다. |
| 혼화 상태 | 급속분사교반기는 미사용, 낙차부 수류식 혼화 | 혼화기 가동상태·가동지수·낙차고 태그가 추가되면 후속 피처로 반영한다. |
| 시설 리스크 | 수류식 혼화강도는 수온·가동지수에 따라 낮아질 수 있고, 약품동~착수정 이격거리는 약 270m | 현재 Parquet에 해당 상태 태그가 없으므로 모델 한계와 추가 데이터 항목으로 관리한다. |
| Jar-test·플록 분석 | Jar-test와 iPDA-250A 응집플록분석장치를 운영 | Jar-test 이력과 iPDA 결과는 현재 Parquet에 없으므로 비교 단계의 입력에서 제외한다. |

진단서에는 Jar-test 기록을 차세대 상수도 정보시스템에 일 2회 입력한다고 적힌 부분과 수행이력이 없다고 요약한 부분이 함께 있다. 실제 시스템에서 추출 가능한 이력을 확인한 뒤에만 후속 학습 데이터로 포함한다.

## 5. 비교용 목표값과 시간 설계

### 5.1 비교용 정답값

실제 PAC 유량 태그가 0으로 고정돼 있고 PAHCS 사용 상태도 파일에 없으므로, 이번 비교는 다음 설정값을 각각 독립된 정답값으로 사용한다.

1. 주 목표: `DCS.PAC 투입량 설정 #2`
2. 보조 목표: `DCS.기존 PAC 주입률 설정 #1`

두 목표값은 실제 투입 mg/L로 해석하지 않는다. 단위, PAC/PAHCS 운전 상태, 설정값과 실제 주입량의 일치 여부가 확인된 뒤에만 후속 최적 주입량 모델의 정답값 후보가 된다.

### 5.2 시간 정렬

각 분 `t`의 원수·운전 입력으로 같은 시각 `t`의 비교용 설정값을 예측한다. 예측값은 설비에 전달하거나 운전자에게 추천하지 않는다.

`t 이전 원수·공정 입력 -> t 시점의 PAC 설정값 예측 -> 후보 모델별 오차 비교`

침전지·여과지·정수지 수질을 성능 목표로 확장하려면, 응집제 주입점부터 각 측정점까지의 실제 체류시간을 별도 검증해야 한다. 진단서의 수류 혼화 특성과 계통별 운영상태를 고려해 추적자 시험 또는 주입변경 반응 분석으로 지연시간을 산정한다.

## 6. 후보 모델풀 성능 비교

| 후보 모델 | 비교 목적 | 입력 방식 |
| --- | --- | --- |
| 다변수 회귀 | 설명 가능한 기준선 | `t` 시점 및 5/15/60분 지연 피처 |
| XGBoost | 비선형 수질·운전 관계와 탭형 데이터 비교 | 다변수 회귀와 동일 피처 |
| Random Forest | 이상치·비선형 관계에 대한 강건성 비교 | 다변수 회귀와 동일 피처 |
| GRU | 계절·반복운전·단기 시계열 의존성 비교 | 동일 피처의 60/120/360분 입력창 |
| LSTM | 장기 시계열·누적 수질 변동 비교 | 동일 피처의 60/120/360분 입력창 |

모든 모델은 기본 피처 세트(원수 pH·탁도·온도·알카리도, 시간 피처, 직전 설정값)로 먼저 비교한다. 이후 유량과 전기전도도가 함께 존재하는 공통 완전구간에서 보조 피처 세트를 추가해 성능 변화만 별도로 비교한다.

학습·검증·시험은 시간순으로 분리한다. 최근 시험 구간은 모델 선택·튜닝에 사용하지 않으며, 각 모델·각 목표값·각 입력창에 동일한 구간을 적용한다. 비교 지표는 MAE, RMSE, R², 추론시간, 계절·원수탁도 구간별 오차, 학습에서 제외된 행 비율이다.

## 7. 피처 간 상관·변환 분석

피처 선별 시 원본 상관 하나만 보지 않는다. 원수 수질·유량·약품 설정값·시간 피처와 비교용 목표값에 대해 다음 분석을 같은 학습 구간에서 수행한다.

| 분석 방법 | 적용 목적 | 주의사항 |
| --- | --- | --- |
| Pearson 상관 | 선형 관계·다중공선성의 1차 확인 | 이상치와 비선형 관계에 민감하므로 단독 기준으로 쓰지 않는다. |
| Spearman·Kendall 상관 | 순위 기반 단조 관계 확인 | 계단형 설정값의 동률 비율을 함께 기록한다. |
| 로그 변환 상관 | 탁도·유량처럼 양수이고 오른쪽 꼬리가 긴 변수의 관계 탐색 | 0·음수에는 직접 로그를 적용하지 않고 `log1p(x)` 또는 유효 양수 구간을 사용한다. |
| 제곱근 변환 상관 | 작은 값이 밀집된 양수 변수의 분산 완화 | 음수는 센서 이상 여부를 먼저 판정한다. |
| 제곱 변환 상관 | 큰 값에서 영향이 급격히 커지는 관계 탐색 | 스케일링과 극단값 영향을 확인한다. |
| 시차 상관 | 원수 변화와 이후 설정값 변화의 관계 탐색 | 미래 값을 `t` 시점 모델 입력에 쓰지 않는다. |

상관이 높다는 이유만으로 피처를 제거하지 않는다. 다변수 회귀에서는 VIF를 추가로 점검하고, 트리·시계열 모델에서는 시간순 시험 성능과 중요도 분석을 함께 보며, 공정상 의미와 센서 위치를 기준으로 최종 유지 여부를 정한다.

## 8. 데이터 품질 규칙

- 기본 학습 행에는 시간키, 선택된 목표값, 원수 pH·탁도·온도·알카리도, 해당 플래그 상태가 모두 있어야 한다.
- `DCS.PAC #1 FLOW`와 전부 결측인 `DCS.전염소 투입량`은 자동 제외한다.
- 0 또는 음수는 변수마다 의미가 다르다. pH 0은 무효로 처리하고, 탁도 0·유량 0은 설비 정지·센서 상태·전후 시계열을 확인한 뒤 처리한다.
- 여과지 탁도의 극단값 등 범위 이탈은 원본을 보존하되 모델용 품질 플래그를 별도로 생성한다.
- 결측이 큰 유량·전기전도도·침전/여과 탁도는 전체 기간의 임의 보간을 하지 않는다.
- 무작위 교차검증은 사용하지 않고 시간순 검증만 사용한다.

## 9. 1단계 수행 순서와 완료 기준

1. 67개 태그의 단위, 설비 위치, 설정값/실측값, `_flag`·`_src` 코드 의미를 확정한다.
2. 기본 피처 세트와 유량·전기전도도 보조 피처 세트를 각각 생성한다.
3. 주·보조 목표값을 분리하고, 같은 시간순 학습·검증·시험 구간을 설정한다.
4. 다변수 회귀, XGBoost, Random Forest, GRU, LSTM을 각각 학습한다.
5. GRU·LSTM은 60·120·360분 입력창을 비교하고, 나머지 모델은 같은 시점 피처를 사용한다.
6. 목표값·모델·피처 세트별 성능표와 상관·변환 분석표를 작성한다.

1단계의 완료 기준은 모델별 시험 성능, 피처별 기여와 한계, 결측으로 인한 적용 가능 범위가 재현 가능한 비교 보고서로 정리되는 것이다. 실제 약품 사용 종류·실제 주입량·Jar-test 이력이 연결된 뒤에만 추천 또는 자동제어의 후속 단계를 검토한다.
