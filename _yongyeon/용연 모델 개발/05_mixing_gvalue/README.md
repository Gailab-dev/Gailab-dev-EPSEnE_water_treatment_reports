# 05_mixing_gvalue — 용연 교반기(플록큐레이터) G값·RPM 산정 모듈

플록형성지 플록큐레이터(수평패들형 3단 점감, 7지×9대, 인버터 변속)의 **교반강도
G값 산정**과 **목표 G 달성 RPM 역산**. 덕남 모듈 이식본으로, 용연 기술진단서
(제2장) 제원·수치표로 재캘리브레이션했다.

## 실행

```bash
cd 05_mixing_gvalue
python run_mixing_g.py     # 검증 → 조견표 → 지별 진단 → 일별 권장 rpm (수 초)
```

## 공식과 이원 캘리브레이션

```
G = K0 · √(ρ(T)/μ(T)) · rpm^1.5          (G값 산정)
rpm = (G_target / (K0·√(ρ/μ)))^(2/3)     (RPM 역산)
Gt  = Σ G_i × t_i,  t_i = (지체적/3 × 가동지수) / 유량
수류혼화 G = √(γ·h_l / (μ·t))            (착수정 낙차부, h=0.58m 보완조사)
```

진단서에는 **계수가 1.21배 다른 두 표**가 있고 각각 내부적으로 수온·단별
일관(둘 다 G∝rpm^1.5 확인)하며 주변속도(유효반경)는 동일하다. 이는 문서 내
저항·유효체적 파라미터를 다르게 잡은 진단서 내부 산정 차이이며(모순이 아니라
용도별 이원 산정), **본 모듈은 각 산출물을 해당 표와 일치시키기 위해 계수를
이원화**한다:

- **K0_DIAG = 0.01570** — **지별 운영 표(2.3-10/11)**, 실측 rpm→G.
  앵커 15℃ #1지 1단 1.82rpm↔G36.1. **지별 진단·기준 판정·Gt**에 사용.
- **K0_STD = 0.01902** — **표준운영조건 조견표(2.3-12)**, 목표 G→권장 rpm.
  앵커 15℃ 1단 1.99rpm↔G50. **수온별 권장 RPM 조견표·일별 권장 rpm**에 사용.
- 두 표 공통: 유효반경 R=1.754m(v/rpm≈18.35), 목표 G 점감 50/30/10.
  → `rpm_for_g`와 `g_from_rpm`은 서로 정확한 역함수가 아님(의도적, 두 표 재현).
- 지 체적: 기하체적 1,027.8㎥/지(B17.6×L14.6×H4.0) × 7지 — **진단서 체류시간
  (평균 37.5분)·Gt(#1지 6.3×10⁴)를 이 값으로 재현**함을 확인(776㎥ 쓰면 27% 오차).
  표 2.3-1의 "776㎥/지 × 12지" 표기는 진단서 자체 오기(용연은 7지).

**검증 (실행 시 자동 assert)**:
- 지별 진단 표 2.3-10/11 (15℃·5℃ 지별 G 42개): **최대오차 1.26%** (K0_DIAG)
- 표준운영 조견표 2.3-12 (수온 6종 × 3단 rpm 18개): **최대오차 0.84%** (K0_STD)
- 표 2.2-4 보완조사 수류혼화 G(설계 20℃ 571.1/sec): 오차 0.2%
- 주변속도 33.43cm/s@1.82rpm: 정확 일치
- Gt(#1지 15℃ 평균유량): 6.1×10⁴ (표 6.3×10⁴, 2.9%)

## 결과 요약

- **지별 운영 진단**(K0_DIAG): 최악조건(5℃·최대유량)·평균조건(15℃·평균유량) 모두
  **7지 전부 적정** (G 50~10 점감 기준 내, 3단 하한 충족) — 진단서 결론
  ("기준 범위 내 운영") 재현. 덕남(8지 중 5지 이상)과 대조적으로 양호.
- **수온별 권장 RPM 조견표**(K0_STD): 진단서 표 2.3-12와 일치
  (예: G50/30/10@15℃ → 1.99/1.42/0.68rpm).
- **일별 권장 rpm** (원수 온도 1,965일 연계, K0_STD): 저수온기(<10℃) 1단 평균
  2.15rpm vs 고수온기(>20℃) 1.87rpm — 겨울 점도 보상 정량화.
