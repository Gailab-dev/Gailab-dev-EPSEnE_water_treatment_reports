# 03_dose_recommend — 용연 응집제 투입량 추천 (덕남 이식본)

02_coag 침전 탁도 예측 파이프라인을 재사용해, 주입률(`PAC주입률_평균PV`)을
강제 포함하고 **단조 제약(주입률↑→탁도↓) XGBoost**를 재학습한 뒤,
주입률 후보 what-if 스윕으로 **목표 침전 탁도(0.7NTU)를 만족하는 최소
주입률**을 추천한다.

## 실행

```bash
cd 03_dose_recommend
python run_recommend.py     # 군집별 재학습 → 백테스트 → 리포트
```

## 구성 (덕남과 동일 원리)

- 그리드 8~24ppm(0.5 간격) 스윕 → 후보축 누적최소로 단조 비증가 보장
- **데이터 지지구간(학습 주입률 P5~P95) 밖 탐색 금지** (외삽 방지)
- 램프 ±2ppm/스텝, 목표 0.7NTU − 마진 0.05 (침전수 운영 95% 0.65NTU 근거)
- 소표본 군집(cluster2 강우 이벤트) 제외

## 백테스트 결과 (test)

| 군집 | 지지구간(ppm) | 평균 실제→추천 | 추천>실제 | 실제 목표초과 | 목표달성가능 | 모델 R² |
|---|---|---|---|---|---|---|
| cluster0 | 5.6~8.8 | 6.86 → 8.01 | 82.6% | 6.5% | 98.1% | 0.17 |
| cluster1 | 6.8~9.5 | 7.78 → 8.42 | 58.8% | **26.4%** | 71.0% | 0.42 |
| cluster2 | — | 데이터 부족 제외 | | | | |

**덕남과 반대 방향의 결론**: 덕남은 절감 여지(추천<실제)가 났지만, 용연은
**증량 권고가 지배적**이다 — 실제 침전 탁도가 목표 0.7NTU를 초과하는 시간이
cluster1에서 26.4%에 달해, 모델이 지지구간 상한까지 증량을 요구한다.
cluster1은 상한(9.5ppm)으로도 목표 미달 예측이 29%로, **주입률 상향 또는
목표 재설정 검토가 필요한 신호**다.

## 한계

1. **추천 모델의 예측력 자체가 약함** (R² 0.17/0.42) — 02_coag의 persistence
   하한 문제와 동일 원인. 추천은 방향성 참고로만 사용하고, 실제 적용 전
   침전 탁도 모델 개선(강우 이벤트 데이터 축적, 지별 운영 태그)이 선행돼야 한다.
2. dose 피처(활성 PV 평균 ~7-9ppm)는 진단서의 PAC 주입률(평균 15.6ppm)과
   기준이 다르다(라인별 PV vs 전체 환산 ppm 추정) — 절대값 해석 시 태그
   정의 확인 필요. 모델 내부적으로는 일관된 상대 지표로 동작.
3. 덕남과 동일하게 dose-response의 인과 식별은 관측 데이터 한계 내에 있음 —
   Jar-test 기록 연계 권장.
