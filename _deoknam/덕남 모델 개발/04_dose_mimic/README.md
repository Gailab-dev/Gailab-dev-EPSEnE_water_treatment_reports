# 04_dose_mimic — 응집제 주입률 운영자 모사 모델 (무인 운전용)

과거 운영 데이터로 주입률 결정을 재현(모사)하는 모델. **절감·최적화 목적이 아니며**
(그건 03_dose_recommend), 무인 운전 시 관행 수준의 주입률 유지가 목적이다.

## 실행

```bash
cd 04_dose_mimic
python run_mimic.py
```

## 구성

- 프레임: **일 단위 5클래스 분류** (SV 13~17ppm). 10분 회귀는 persistence 함정으로 무의미.
- 데이터: 전처리 parquet 일 집계 580일 — 원수성상(탁도·log·7일최대·변화량, pH, 알칼리도,
  수온·7일변화, 전도도), 처리량, 전일 침전 탁도, 계절(sin/cos), 어제 SV(AR).
- 모델: XGBoost 분류기 × 계열(1/2) × AR 포함/제외 2종. 학습창에 없는 클래스 압축 매핑.
- 평가: (a) 시간순 홀드아웃(116일), (b) **워크포워드**(초기 180일 학습, 30일마다 재학습,
  400일 평가 — 변경 이벤트 14회 포함).

## 결과 (정직 보고)

**운영 특성**: 주입률 변경은 623일간 계열1 33회/계열2 36회(평균 ~19일에 1회),
일 단위 "어제 값 유지"(persistence) 적중률 97.1%.

| 평가 | 모사 정확도 | persistence | 변경감지 재현율/정밀도 | 변경일 값적중 |
|---|---|---|---|---|
| 홀드아웃 116일 (변경 0회) | 84.5~99.1% | **100%** | - | - |
| 워크포워드 400일 (변경 14회) | 69.0% | **96.5%** | 57% / **6.6%** (오경보 113일) | 21.4% |

- **ML 모사 모델은 persistence에 완패한다.** 변경을 절반쯤 감지하지만 오경보가
  8배 많고(정밀도 6.6%), 변경일의 값도 21%만 맞힌다.
- AR 제외(순수 조건 기반) 정확도는 8.6~33.6% — **주입률 레벨(15 vs 16)은 수질
  조건으로 설명되지 않는 운영 재량**임을 재확인.
- 변경 이벤트 조건 분석(`계열N_변경이벤트_조건.csv`): 증량(TB중앙 2.5NTU)과
  감량(2.1NTU)의 조건 분포가 겹쳐 뚜렷한 규칙이 없다.

## 결론 및 무인화 권고

**이 데이터에서 최선의 "온전한 모사 정책"은 ML이 아니라 규칙이다:**

```
기본: 어제 주입률 유지 (persistence, 96.5~97% 재현)
예외: 03_dose_recommend의 목표달성가능=False(고탁도 대응) 시 증량 경보 → 운영자 승인
변경: 정기 변경(계절 전환 등)은 운영자 결정 사항으로 유지
```

ML 분류기 번들(`output/models/dose_mimic_xgb.pkl`)은 참고용으로 저장돼 있으나
운영 투입은 권고하지 않는다. 무인화 수준을 높이려면 변경 결정의 근거가 기록으로
남아야 하며(변경 사유 로그), 이는 1~2단계 개선(Jar-test 기록·주입률 실험)과 함께
축적 시 재학습 가치가 생긴다.
