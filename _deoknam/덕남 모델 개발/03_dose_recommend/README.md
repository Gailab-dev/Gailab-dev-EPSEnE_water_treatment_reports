# 03_dose_recommend — 응집제 투입량 추천

02_coag 침전 탁도 예측 모델을 **역산(what-if)**하여, 목표 침전 탁도를 만족하는
**최소 응집제 주입률(PAC SV, ppm)**을 군집별로 추천한다.

## 실행

```bash
cd 03_dose_recommend
python run_recommend.py     # 군집별 재학습 → 백테스트 → 리포트 (~5분)
```

## 왜 역산 방식인가

원수성상→주입률 직접 회귀는 기존 연구(덕남_응집제_투입량 task2)에서 실패했다
(R² ≤ 0.51). 주입률은 12~24ppm 준이산 계단값이고 과거 주입률은 운영자 판단의
기록이라, 이를 학습하면 운영자 모사일 뿐 최적화가 아니다. 기존 보고서 권고대로
**탁도 모델을 역산해 목표를 만족하는 최소 주입률**을 찾는다.

## 구성

```
실시간 피처 → ①군집판정(01_clustering) → ②단조제약 탁도모델 → ③what-if 스윕
            → ④제약(지지구간·램프·목표마진) → 추천 주입률 + 예측 근거
```

1. **추천 전용 모델** (`dose_model.py`): 02_coag best 모델은 피처 선택에서 주입률이
   빠질 수 있어 역산 불가 → 주입률 **강제 포함** 15피처(원수성상5 + 주입률 + 유량 +
   AR2 + 추세6), XGBoost `monotone_constraints`로 **주입률↑→탁도↓ 단조 제약**,
   침전지별 단일출력 2모델/군집. 타깃·분할·lag는 02_coag와 동일(델타·1h평활·시간순).
2. **what-if 스윕** (`recommender.py`): 주입률 후보(12~24ppm, 0.5 간격)로 치환해
   침전지1·2 탁도 예측, 후보축 누적최소로 단조 비증가 보장.
3. **제약**:
   - **목표**: 침전지1·2 모두 0.5NTU − 마진 0.05 이하 (config.TARGET_NTU)
   - **데이터 지지구간**: 학습 주입률 P5~P95 밖 후보는 탐색 제외 (외삽 금지, 아래 한계)
   - **램프**: 현재 주입률 대비 ±2ppm/스텝 클립
   - **폴백**: 목표 달성 불가 시 지지구간 상한 + `목표달성가능=False` 플래그

## 백테스트 결과 (test 구간)

| 군집 | 지지구간(ppm) | 평균 실제→추천 | 추천<실제 시간 | 그때 실제탁도 목표만족 | 모델 test R²(b1/b2) |
|---|---|---|---|---|---|
| cluster0 | 15.0~16.0 | 15.00 → 15.00 | 0% | - | -1.39 / 0.85 |
| cluster1 | 15.0~16.0 | 15.39 → 15.01 | 38.6% | 100% | 0.94 / 0.22 |
| cluster2 | 14.0~17.0 | 15.00 → 14.00 | 100% | 100% | 0.50 / 0.83 |

- 단조성 검증 통과(전 군집), 목표달성가능 99.3~100%.
- **c1은 약 0.4ppm, c2는 약 1ppm 절감 여지**가 데이터 지지 범위 안에서 확인됨 —
  추천이 낮았던 전 구간에서 실제 침전 탁도가 목표(0.5NTU)를 만족했다.
- c2는 탁도 이벤트 시점에 추천이 자동 상향(주입률 시계열 png 참고).

## 핵심 한계 (반드시 읽을 것)

**dose-response 식별 한계**: 학습 데이터의 주입률이 15~16ppm에 밀집(std 0.5~0.75ppm,
c0은 고유값 3개)되어 있어, 그 밖의 주입률 효과는 데이터로 알 수 없다(12→24ppm
스윕 시 예측 탁도 변화가 c0/c1에서 ~0.003NTU에 불과). 지지구간 제한이 없으면
추천이 그리드 최소(12ppm)로 수렴하는 **비식별 외삽**이 발생한다 — 그래서 탐색을
P5~P95로 제한했고, 현재 추천의 절감폭(0.4~1ppm)은 관측된 운영 범위 안의 보수적
값이다. **추천 범위를 넓히려면**: (a) Jar-test 결과로 dose-response 보정,
(b) 의도적 주입률 변경 실험(예: ±2ppm 계획 변경) 데이터 축적, (c) 조견표 하한을
안전 하한으로 결합.
