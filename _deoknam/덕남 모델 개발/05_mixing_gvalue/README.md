# 05_mixing_gvalue — 교반기(플록큐레이터) G값·RPM 산정 모듈

플록형성지 플록큐레이터(수평패들형 3단 점감, 인버터 변속)의 **교반강도 G값 산정**과
**목표 G 달성에 필요한 회전수(RPM) 역산**. 기술진단서(제2장) 지적사항 — 단별 G값
편차, 3단 기준(10/sec) 미달, 수온별 회전수 조정 필요 — 을 계산 모듈로 자동화한다.

## 실행

```bash
cd 05_mixing_gvalue
python run_mixing_g.py     # 검증 → 조견표 → 지별 진단 → 일별 권장 rpm (수 초)
```

## 공식과 캘리브레이션

패들 교반 이론 `P = C_D·A·ρ·v³/2`, `G = √(P/(μV))`에서 기하 인자(C_D·ΣA·r³,
slip 계수, 단 체적)를 상수 K0로 묶으면:

```
G = K0 · √(ρ(T)/μ(T)) · rpm^1.5          (G값 산정)
rpm = (G_target / (K0·√(ρ/μ)))^(2/3)     (RPM 역산, 해석적)
Gt  = Σ G_i × t_i,  t_i = (지체적/3 × 가동지수) / 유량
수류혼화 G = √(γ·h_l / (μ·t))            (착수정 낙차부, h=0.45m)
```

- **K0 = 0.02094** — 기술진단서 표준운영조건 표(2.3-13)의 25℃·1단 G50↔1.72rpm에서 역산.
- 물성 ρ(T)·μ(T)는 0~35℃ 표준표 선형보간 (`water.py`).
- 유효반경 R=1.847m — 진단서 주변속도(v/rpm=19.34cm/s)에서 역산.

**검증 (진단서 수치 재현, 실행 시 assert)**:
- 표 2.3-13 (수온 5~30℃ × 3단 필요 rpm 18개 값): **최대오차 0.57%**
- 표 2.3-12 (5℃ 지별 실측 rpm → G값): 오차 ≤1.6%
- 표 2.2-4 (수류혼화 G, 20℃): 오차 0.3% / 주변속도 33.27cm/s 정확 일치
- Gt 표준조건 1.06×10⁵ (표 1.1×10⁵, 반올림 차이)

참고: 진단서 표 2.3-11(평균운영조건, "25℃" 표기)의 G값은 25℃ 물성과 맞지 않고
~10℃ 물성과 정합한다(표 2.3-12·2.3-13은 자체 일관). 본 모듈은 일관된 표들로
캘리브레이션했다.

4지) 완료 지부터 이 시계열로 수온 연동 운전 가능.

## 사용 예

```python
from mixing_g import gvalue

gvalue.g_from_rpm(1.2, temp_c=8)          # 현재 rpm → G값
gvalue.rpm_for_g(50, temp_c=8)            # 목표 G → 필요 rpm
gvalue.gt([2.0, 1.4, 0.7], 8, 227728)     # 단별 G, Gt (유량·수온 반영)
gvalue.hydraulic_g(8, hrt_s=99.1)         # 착수정 낙차 혼화 G
```

## 한계

- K0는 진단서 계산표 기준 캘리브레이션 — 패들 개조·수위 변화 시 재보정 필요.
- Gt의 체류시간은 총유량·가동지수 기반(진단서 방식) — 지별 유량 편차(10~16%)는 미반영.
- 목표 G(50/30/10)는 Kawamura 권고이며, 원수 조건별 최적 G는 응집플록분석장치
  도입 후 데이터로 재탐색하는 것이 다음 단계.
