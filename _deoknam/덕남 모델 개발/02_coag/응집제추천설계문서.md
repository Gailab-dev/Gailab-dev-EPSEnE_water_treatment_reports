# 덕남정수장 응집공정 AI 알고리즘 상세설계문서

## 1. 목적과 범위

본 문서는 전처리가 완료된 `덕남_응집제공정_소독공정_통합.parquet`을 입력으로 사용하여, 체류시간 산정부터 모델 성능 비교, 침전수 탁도 예측, 응집제 주입률 산정, 운영 검증과 피드백까지의 설계를 정의한다.

구축은 다음 단계로 분리한다.

| 단계 | 범위 | 출력 |
| --- | --- | --- |
| 1단계 | 체류시간 산정·시간정렬·피처 생성·후보 모델풀 성능 비교 | 모델별 시험 성능표와 선정 근거 |
| 2단계 | 후보 주입률별 침전수 탁도 공정반응 모델과 제약조건 기반 최적화 | 운전자용 추천 주입률 |
| 3단계 | 그림자 운전·승인형 운전·피드백 보정 | 현장 검증 결과와 제한 자동화 검토자료 |

전처리 로직의 재설계, 원천 데이터 수집시스템 변경, 즉시 자동제어는 본 문서의 범위에서 제외한다.

## 2. 전체 구조

```text
전처리 완료 데이터
  → 체류시간 산정
  → 주입시점-침전지 출수부 탁도센서 시간정렬
  → 시차·변환·운전상태 피처 생성
  → 수질구간 분석
  → 후보 모델풀 성능 비교
  → 공정반응 모델 선정
  → 후보 주입률별 미래 침전수 탁도 예측
  → 목표 수질·약품량·변경폭 기반 최적화
  → 안전제약·모델 신뢰도 검사
  → 운전자 추천
  → 실제 출수부 탁도와 비교·피드백
```

핵심 원칙은 과거 설정값을 예측하는 모델과 후보 주입률의 처리 결과를 예측하는 모델을 분리하는 것이다.

- 설정값 모사 모델: 현재 운전 패턴의 예측 가능성과 후보 모델 성능을 비교한다.
- 공정반응 모델: 원수 상태와 후보 주입률을 넣어 미래 침전수 탁도를 예측한다.
- 최적화 모듈: 공정반응 모델을 반복 호출하여 목표 탁도를 만족하는 최소·안정 주입률을 찾는다.

## 3. 사용 데이터

### 3.1 주입시점 입력

| 구분 | 태그 |
| --- | --- |
| 원수 수질 | `RCS_6.AI.착수정_PH`, `RCS_6.AI.착수정_TB`, `RCS_6.AI.착수정_AL`, `RCS_6.AI.착수정_온도`, `RCS_6.AI.착수정_전기전도도` |
| 유량·수위 | `RCS_1.AI.FT101`, `RCS_1.AI.LT301`, `RCS_1.AI.LT302` |
| 응집제 설정 | PAC/PACS2 목표주입량, 주입률제어 SV, 주입량제어 SV |
| 실제 주입상태 후보 | 주입 유량1·2, 주입량 A1·B1·A2·B2, 적산값 |
| 운전조건 | 전·중염소 주입조건, 시간대, 월, 계절, 직전 설정 변경 후 경과시간 |

### 3.2 출수부 결과

| 구분 | 태그 | 용도 |
| --- | --- | --- |
| 침전수 탁도 | `RCS_6.AI.침전지1_탁도`, `RCS_6.AI.침전지2_탁도` | 공정반응 모델의 핵심 출력 |
| 침전수 pH | `RCS_6.AI.침전지1_PH`, `RCS_6.AI.침전지2_PH` | 보조 품질 출력·제약조건 |
| 여과·정수지 수질 | 여과지·정수지 탁도와 pH | 장기 품질 감시지표, 주입 직전 모델의 입력으로는 사용하지 않음 |

### 3.3 필수 추가 데이터

현재 PAC와 PACS2 설정값이 동일 시각에 함께 존재하므로 다음 필드가 확인되기 전에는 실제 약품 최적화를 운영에 적용하지 않는다.

- 실제 사용 응집제: `active_coagulant`
- 실제 PAC 및 PACS2 주입량: `actual_pac_mgL`, `actual_pacs2_mgL`
- 약품 농도·밀도·교체 시각
- 펌프·라인별 태그와 약품의 확정 매핑
- 계열별 가동 침전지 수와 유량분배율
- 침전수 탁도센서 채수배관 길이와 분석기 응답시간

PAC와 PACS2 설정값을 단순 합산하지 않는다. 실제 동시 투입이 확인된 경우에만 물질수지용 유효성분량을 다음과 같이 산정한다.

```text
Al2O3 환산량 = actual_pac_mgL × 0.105
             + actual_pacs2_mgL × 0.11
```

두 약품의 염기도와 응집 특성이 다르므로 공정반응 모델에는 PAC·PACS2 실제 투입량과 약품 종류를 각각 유지한다.

## 4. 체류시간 산정

### 4.1 시간 기준점

- 시작점: 착수정 낙차부 응집제 실제 주입시각
- 종료점: 침전지 출수부 탁도센서가 해당 처리수를 측정한 시각
- 총 지연시간 명칭: `T_outlet`

진단서의 약 11.3분은 응집제 주입 후 플록형성지 유입부까지의 평균유량 기준 시간이며, 출수부 탁도센서까지의 전체 지연시간이 아니다.

### 4.2 이론 체류시간

```text
T_outlet(t)
  = T_주입후수로(t)
  + T_혼화·플록이송(t)
  + T_플록형성지(t)
  + T_침전지(t)
  + T_채수배관·센서
```

각 공정조의 이론 체류시간은 다음 식으로 계산한다.

```text
T_i(t) = V_i,active(t) / Q_i(t)
```

- `V_i,active`: 해당 시점에 가동 중인 시설의 유효용량
- `Q_i`: 해당 계열을 통과하는 유량
- 병렬 계열은 전체 `FT101` 유량을 그대로 사용하지 않고 계열별 유량분배율을 적용

진단서의 11.3분을 기준으로 혼화·이송 구간을 보정할 때는 다음 식을 사용할 수 있다.

```text
T_mix(t) = 11.3분 × Q_reference / Q(t)
```

`Q_reference`는 진단서에서 11.3분 산정에 사용한 평균유량으로 확정하며, 가동 계열이나 유효용량이 변경되면 기준식을 다시 계산한다.

### 4.3 실제 지연시간 보정

이론값은 다음 방법으로 검증한다.

1. 추적자 시험 또는 현장 수리자료로 출수부 도달시간과 체류시간분포를 확인한다.
2. 원수탁도·실제 주입률이 명확히 변화한 운전 이벤트를 추출한다.
3. 수리계산으로 정한 허용범위 안에서 시차상관과 DTW를 계산한다.
4. 유량·계절·가동지수 구간별로 공정반응 모델의 검증오차가 최소인 시차를 비교한다.
5. 물리적으로 설명되지 않는 데이터 기반 시차는 채택하지 않는다.

최종 지연시간은 다음 중 데이터가 지지하는 가장 단순한 형태를 선택한다.

- 고정형: `T_outlet = 상수`
- 유량보정형: `T_outlet = a / Q + b`
- 계열형: `T_outlet = f(Q, 가동지수, 계열)`

## 5. 시간정렬

### 5.1 공정반응 학습자료

각 주입시점 `t`의 입력을 `t + T_outlet(t)`의 침전지 출수부 결과와 연결한다.

```text
X(t)
  = 원수 수질(t)
  + 유량·수위(t)
  + 실제 약품 종류(t)
  + 실제 주입률(t)
  + 직전 운전상태(t)

y1(t) = 침전지1_탁도[t + T_outlet,1(t)]
y2(t) = 침전지2_탁도[t + T_outlet,2(t)]
```

침전지1·2가 서로 다른 계열의 출수부 센서이면 계열별 지연시간과 모델을 분리한다. 동일 계통의 중복 센서이면 센서 정상상태를 확인한 뒤 대표값을 산출한다.

### 5.2 체류시간분포 반영

침전지는 완전한 플러그 흐름이 아니므로 단일 시점만 정답으로 쓰는 방식과 출수부 시간창을 쓰는 방식을 함께 비교한다.

```text
단일점 목표 = TB[t + T_outlet]
시간창 목표 = median(TB[t + T_outlet - Δ : t + T_outlet + Δ])
위험 목표   = max(TB[t + T_outlet - Δ : t + T_outlet + Δ])
```

`Δ`는 추적자 시험의 체류시간분포 폭 또는 검증오차를 기준으로 결정한다. 초기 후보는 3·5·10분으로 비교한다.

최종 보수적 품질지표는 두 계열 센서가 모두 정상일 때 다음과 같이 정의한다.

```text
TB_outlet = max(TB_침전지1, TB_침전지2)
```

### 5.3 정렬 규칙

- `T_outlet`이 정수가 아니면 가장 가까운 1분값 또는 선형보간을 비교한다.
- 센서 허용시각 오차는 기본 ±1분이며, 초과 시 해당 학습 행을 제외한다.
- 체류시간 구간 중 펌프·계열·유량이 급변한 행은 혼합 상태로 표시하거나 제외한다.
- 출수부 탁도와 pH 등 미래 결과값은 주입시점 모델의 입력으로 사용하지 않는다.

## 6. 피처 생성과 관계분석

전처리 완료 원시 피처에서 다음 파생변수를 생성한다.

- 5·15·30·60분 지연값
- 5·15·60분 변화량과 변화율
- 15·60·180분 이동평균·최솟값·최댓값·표준편차
- 직전 주입률, 마지막 주입률 변경 후 경과시간, 변경폭
- `T_outlet`, 유량구간, 수온구간, 계절, 시간대
- 저탁도·중탁도·고탁도 및 급상승 상태
- 센서 가용성·모델 적용가능성 플래그

피처 간 관계는 다음 방법을 모두 비교한다.

| 방법 | 목적 |
| --- | --- |
| Pearson | 선형관계와 다중공선성 확인 |
| Spearman·Kendall | 비선형 단조관계와 계단형 설정값 분석 |
| 로그 상관 | 탁도·유량 등 오른쪽 꼬리가 긴 양수 변수 분석 |
| 제곱근 상관 | 작은 값이 밀집된 변수의 분산 완화 |
| 제곱 상관 | 큰 값에서 영향이 커지는 관계 탐색 |
| 시차 상관·DTW | 체류시간과 지연 반응 검증 |

0·음수값에는 직접 로그를 적용하지 않고, 측정 의미를 확인한 뒤 `log1p` 또는 유효 양수 구간을 사용한다. 다변수 회귀는 VIF를 추가 점검한다. 상관분석은 인과관계나 피처 삭제의 단독 기준으로 사용하지 않는다.

군집화는 필수 전처리 단계가 아니라 다음 목적으로만 사용한다.

- 계절·수온·원수탁도·유량별 수질군 정의
- 후보 모델의 취약구간 비교
- 학습범위 밖 원수 상태 탐지

## 7. 후보 모델풀 성능 비교

### 7.1 비교 과제

| 과제 | 입력 | 출력 | 목적 |
| --- | --- | --- | --- |
| A. 설정값 모사 | 주입시점 원수·유량·직전 설정 | PAC 또는 PACS2 설정값 | 모델풀의 기본 예측성능 비교 |
| B. 공정반응 예측 | 주입시점 원수·유량·약품 종류·실제 후보 주입률 | `T_outlet` 후 침전수 탁도 | 최적 주입률 탐색에 사용할 모델 선정 |

과제 A는 현행 운전 모사 성능을 평가하며 최적 주입률이라고 해석하지 않는다. 최종 추천 구조에는 과제 B의 공정반응 모델을 사용한다.

### 7.2 후보 모델

| 모델 | 역할 |
| --- | --- |
| 다변수 회귀 | 설명 가능한 기준선 |
| XGBoost | 탭형 데이터의 비선형 상호작용 비교 |
| Random Forest | 이상치·구간별 강건성 비교 |
| GRU | 단기·중기 시계열 의존성 비교 |
| LSTM | 장기 시계열·누적변동 비교 |

다변수 회귀·XGBoost·Random Forest에는 같은 시점 및 지연·이동통계 피처를 제공한다. GRU·LSTM에는 같은 피처의 60·120·360분 시퀀스를 각각 시험한다.

### 7.3 학습·평가

- 학습·검증·시험을 시간순으로 분리한다.
- 최근 시험구간은 모델 튜닝과 체류시간 선택에 사용하지 않는다.
- 모든 모델에 동일한 학습·시험 시점과 데이터 제외 규칙을 적용한다.
- 고탁도·급변·계절·유량 구간별 성능을 별도로 보고한다.

평가지표는 다음과 같다.

- MAE, RMSE, R²
- 설정 변경 직후 오차와 연속 오차
- 저·중·고탁도 및 급상승 구간의 MAE
- 예측구간 포함률과 평균 폭
- 학습·추론시간, 결측으로 인한 적용 제외율

1단계 산출물은 목표변수·시간정렬 방식·모델·입력창별 성능 비교표이다. 이 단계에서는 모델을 결합하거나 제어신호를 출력하지 않는다.

## 8. 공정반응 예측

선정된 공정반응 모델은 후보 주입률별 미래 출수부 탁도와 불확실성을 출력한다.

```text
입력  : 원수상태, 유량, 약품종류, 후보주입률, T_outlet, 운전상태
출력  : TB1_hat, TB2_hat, TB_outlet_hat, 예측구간, 적용가능성
```

모델 신뢰도는 다음 조건으로 평가한다.

- 현재 원수 상태가 학습 분포 안에 있는지
- 주요 입력 센서가 정상인지
- 해당 약품·주입률 구간의 학습표본이 충분한지
- 예측모델 간 또는 예측구간의 불확실성이 허용수준 이내인지

학습범위 밖 원수, 고탁도 희소구간, 센서 이상에서는 최적화를 실행하지 않고 Jar-test 또는 현행 조견표를 요청한다.

## 9. 최적 주입률 산정

### 9.1 후보 탐색

현재 주입률 주변과 현장 승인 최소·최대 범위 안에서 후보 주입률을 생성한다. 탐색 간격은 펌프 제어 해상도와 운전부서 승인값으로 설정한다.

각 후보 `d`에 대해 공정반응 모델로 `TB_outlet_hat(d)`를 계산한다.

### 9.2 목적함수

```text
J(d)
 = λ_quality × 목표탁도 초과 페널티
 + λ_dose    × 약품 사용량
 + λ_change  × |d - 현재주입률|
 + λ_risk    × 예측 불확실성
```

목표탁도 초과 페널티는 다른 항보다 우선하도록 설정한다. 목표를 만족하는 후보 중 약품사용량과 설정 변경폭이 가장 작은 후보를 추천한다.

PAC와 PACS2를 교대 사용하는 경우에는 실제 활성 약품에 대해서만 후보를 생성한다. 실제 동시 투입이 확인된 경우에는 `d_PAC`, `d_PACS2`를 별도 변수로 탐색하고, 단순 합계가 아닌 개별 반응과 유효성분량을 함께 평가한다.

### 9.3 제약조건

- 약품별 주입률 최소·최대
- 펌프별 토출량 최소·최대
- 1회 및 단위시간당 최대 변경폭
- 침전수 목표 탁도와 pH 허용범위
- 유량·수위·가동계열 조건
- 모델 신뢰도·학습범위·센서 정상 여부

제약을 만족하는 후보가 없으면 모델은 주입률을 출력하지 않고 `현행 유지`, `Jar-test`, `운전자 검토` 중 하나를 반환한다.

## 10. 추천·제어 흐름

```text
1. 최신 입력과 운전상태 수신
2. T_outlet 계산
3. 모델 적용 가능성 확인
4. 후보 주입률 생성
5. 후보별 미래 침전수 탁도·불확실성 예측
6. 목표탁도 만족 후보 필터링
7. 약품량·변경폭·위험도를 고려해 최종 후보 선택
8. 펌프·변경폭·센서 안전제약 최종 확인
9. 추천값과 근거를 운전자에게 표시
10. T_outlet 이후 실제 출수부 탁도와 비교
```

초기 출력은 다음을 포함한다.

- 현행 주입률과 추천 주입률
- 약품 종류와 후보 탐색범위
- 예상 침전지1·2 탁도와 보수적 출수부 탁도
- 목표탁도 대비 여유
- 예측 신뢰도·적용범위 상태
- 추천 주요 근거와 추천 보류 사유

## 11. 피드백과 재학습

추천시점 `t`의 예측값을 `t + T_outlet(t)`의 실제 출수부 센서값과 연결한다.

```text
예측오차 = 실제 TB_outlet - 예측 TB_outlet
```

피드백은 다음에 사용한다.

- 최근 구간의 예측편향 감시
- 계절·수질군별 성능 저하 탐지
- 추천 후 운전자 수정률 분석
- 체류시간 모델 재검증
- 정기 재학습과 모델 교체 판단

실시간 피드백으로 모델 가중치를 즉시 변경하지 않는다. 검증되지 않은 온라인 학습 대신 승인된 기간의 데이터를 모아 오프라인 재학습·검증 후 모델을 교체한다.

## 12. 장애·예외 처리

| 상황 | 처리 |
| --- | --- |
| 주요 센서 결측·이상 | 추천 중지, 현행 설정 유지, 센서 점검 알림 |
| `FT101` 이상 | 동적 체류시간 계산 중지, 승인된 보수값 또는 추천 보류 |
| 가동계열 정보 불명 | 계열별 공정반응 모델 사용 중지 |
| 실제 약품 종류 불명 | PAC/PACS2 최적화 중지 |
| 학습범위 밖 원수 | Jar-test와 운전자 검토 요청 |
| 목표를 만족하는 후보 없음 | 최대허용 주입률을 자동 적용하지 않고 추천 보류 |
| 모델 서비스 장애 | 현행 조견표·기존 유량비례 제어로 복귀 |

## 13. 검증과 단계별 전환

### 13.1 오프라인 검증

- 체류시간 산정값이 수리자료와 일치하는지 확인
- 고정·유량보정·계열형 시간정렬 비교
- 후보 모델풀의 동일 시험구간 성능 비교
- 침전수 목표 탁도 초과 사례의 과소예측률 평가
- 센서 이상·고탁도·유량급변 시 추천 보류 로직 시험

### 13.2 그림자 운전

모델 추천값을 설비에 전달하지 않고 저장한다. 실제 운전값과 비교하여 예상 수질, 약품량, 운전자 수정 가능성을 평가한다.

### 13.3 운전자 승인형 운전

모델 추천값을 운전자에게 표시하되, 승인 또는 수정 후 기존 제어설비에 반영한다. 수질 악화 없이 추천 정확도와 신뢰도가 유지되는지 확인한다.

### 13.4 제한 자동화 검토

한 계절 이상의 승인형 운전, 비상복귀 시험, 책임체계와 현장 안전성 검토를 통과한 뒤 별도 승인으로 결정한다. 본 문서 자체는 자동제어를 승인하지 않는다.

## 15. 최종 권고

첫 구현은 `T_outlet 산정 → 시간정렬 → 후보 모델풀 비교`로 제한한다. 이후 실제 사용 응집제와 실제 주입량 태그가 검증되면 공정반응 모델과 제약조건 기반 추천을 추가한다. 출수부 탁도센서의 체류시간분포와 계열별 유량을 확인하지 않은 상태에서는 주입률 최적화 결과를 현장 제어에 사용하지 않는다.
